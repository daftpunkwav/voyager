# workspace — Agent default working directory ("its home")

> Language: **English** | [简体中文](README.zh.md)

Contents are user data, **not committed to the repo** (see the root .gitignore; this file is kept via git add -f).

| Subdirectory | Purpose |
|---|---|
| repo/ | GitHub projects cloned by the agent |
| books/ | Books |
| news/ | News and scraped material |
| exports/ | Artifacts generated by the agent (Word/PPT etc.) |
| imports/ | Copies of user-imported files |
| sandbox/ | Container mount directory for code execution |

The agent may create its own categories inside the default working directory; users can also specify additional working directories in settings.
