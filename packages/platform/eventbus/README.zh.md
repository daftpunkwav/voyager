# platform/eventbus — 事件流

> 语言：简体中文 | [English](README.md)

形态：**持久化事件日志（SQLite 只追加表）+ 基于游标的订阅**。

- 进程内：经 asyncio 队列直接推送（落后的订阅者会被标记 `lagged`，可通过其游标追平）；
- 跨进程：消费者共享同一个 `events.db`，各持游标，轮询 `read_after` / `read_missed`；
- 该日志表同时是**审计主干与重放来源**：重启后从游标恢复，任意区间均可重放。

事件流自身的故障是唯一“全局”故障面，因此其实现必须最大程度保守：写入立即落盘，
零丢失的订阅承诺由“游标追平”而非内存队列来兑现。

---

## 用途

持久化事件总线：只追加的 EventLog（sqlite）、发布/订阅 Subscription 队列、用于追平重放的游标存储。

## 配置

无（路径由装配根注入）。

## 扩展点

新读取模式 = EventLog 上的一个方法（有界、加锁）；绝不直接读数据库。

## 已知限制

与模型无关的基础设施；单个 sqlite 文件，保留/清理靠手动。

## 暂缓事项

分段日志文件，以降低保留成本。
