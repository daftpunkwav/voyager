# host

> 语言：简体中文 | [English](README.md)

## 目的

装配根(Runtime 层):扫描各域的模块卡,将它们 wire 起来,把能力桥接为 agent 工具,挂载 gateway,并持有进程生命周期。

## 配置

host.* 设置:域白名单、速率限制。

## 扩展点

新域的出现方式:把带 service.json 的包放入 packages/ 即可 —— host 零改动(扫描 → wire → 桥接 → 挂载)。

## 模型体验

模型无关的胶水层;面向 agent 的体验由各域自身定义。

## 已知限制

单进程装配;多进程拆分是单独的另一项工作。

## 暂缓事项

按域的启动健康门禁。
